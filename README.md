# Gym Plan PWA

A mobile-friendly Progressive Web App for the 12-week gym plan.

## Samsung S23 / Chrome installation

1. Upload these files to a web host that provides **HTTPS**.
2. Open the resulting website in **Chrome on the Samsung S23**.
3. Tap **⋮**.
4. Choose **Install app** or **Add to Home screen**.
5. Name it **Gym Plan**.

For GitHub Pages, create a repository, upload all four files to the repository root, enable
Settings → Pages → Deploy from branch → main/root, then open the generated HTTPS URL on the S23.

The app supports offline use after the first successful load.
