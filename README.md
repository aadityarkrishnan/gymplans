# Workout Plan PWA v2
Upload index.html, manifest.json, sw.js and icon.svg to the ROOT of your GitHub Pages repository.
Enable Pages: Settings → Pages → Deploy from branch → main → / (root).
Open the HTTPS Pages URL on Samsung S23 Chrome → ⋮ → Install app / Add to Home screen.

Updates:
- Maximum 5 simple stretches per day
- Romanian deadlift removed; straight-arm pullover used instead
- Session estimate, completion percentage and calorie estimate
- Existing checkboxes/local progress retained
- Offline PWA support
